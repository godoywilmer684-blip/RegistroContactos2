PROYECTO ANDROID: RegistroContactos
Lenguaje: Java
Base de datos: SQLite
Paquete: com.example.registrocontactos

CÓMO ABRIR:
1. Descomprime RegistroContactos.zip.
2. Abre Android Studio.
3. Selecciona Open y elige la carpeta RegistroContactos (la que contiene settings.gradle).
4. Espera a que termine Gradle Sync. Se necesita conexión a Internet para descargar Gradle y dependencias.
5. Selecciona un emulador o conecta un teléfono Android y activa Depuración USB.
6. Pulsa Run (triángulo verde).

PRUEBAS:
- Registra un contacto con nombre solo letras y teléfono solo dígitos.
- Pulsa Guardar contacto y luego Ver contactos.
- Selecciona un contacto para actualizar, eliminar, compartir, ver imagen o llamar.
- Prueba elegir una imagen desde la galería y tomar una foto.
- El permiso de llamada se solicita al intentar llamar.

NOTAS:
- Las llamadas reales requieren un teléfono con servicio de voz y permiso concedido. En emuladores puede que no se pueda completar una llamada real.
- La aplicación guarda los datos localmente en SQLite dentro del almacenamiento privado de la app.
- Este paquete incluye los archivos fuente; Android Studio descargará las herramientas de compilación necesarias al abrirlo.
